反馈提交到公开 GitHub Issue

从项目卡片点击“反馈 / 纠正”，先预览草稿，再前往 GitHub 登录、检查并提交。网页生成草稿时尚未保存反馈。

只有仓库所有者与已配置的编辑者提交的有效反馈，才会在下一次云端任务中影响项目状态或偏好。其他访客的留言不会改变你的研究偏好。

关闭对应 Issue 后，下一次云端任务会撤销其作用；修改 Issue 后按新内容重新处理。处理后的结果以新的快照和规则为准。

这是公开仓库。请勿在反馈中填写密钥、私人资料或不宜公开的内容；网页不展示原始反馈明细。
